# Code of conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be constructive, assume good faith. Harassment, personal attacks, and bad-faith disruption are not welcome. The repository owner enforces this; unacceptable behavior may be reported via the contact in SECURITY.md and can result in removed comments, blocked users, or rejected contributions.
