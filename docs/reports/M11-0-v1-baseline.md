# M11-0 - v1 mine baseline (census)

Environment: local test server clone (`rusticcraft2-clona`, NeoForge 1.21.1, 286 mods, 10 GB heap), the owner's own disposable copy, not production. Build: branch `m11-0-census` head `2b18e5a` (includes both independent-review rounds). Run: `2026-11-11-7`, seed `8166282070128512702`, generated by v1 (`main` at `ba86813`, all M10 fixes).

Command: `/dawnmine census`, run twice in one server session on the final build; the two result blocks were byte-identical (13 lines each, diffed). An earlier build counted 0 spawners because it did not hold a chunk ticket while scanning and block entities were dropped as chunks unloaded; the independent review caught that and the final build reads all 9.

Walk model (documented in `CensusAnalyzer`): 8-direction steps, at most 1 block rise or fall, head and corner clearance, no drops of more than 1 block. "Unreachable" therefore means "not reachable by that walking rule", not necessarily trapped (a ledge reachable only by a longer fall counts).

## What it says about v1 (matches the owner's playtest)

| Owner finding | Measured |
|---|---|
| No mobs | 9 spawner blocks in the whole mine, none within 8 blocks of the rush route (mobs/100 = 0.0 in every band). Live mobs are not part of the static census. |
| No loot | 0 loot containers in the whole mine. |
| Too little ore | Ore is 0.8% of wall surface. Ore does sit near the route (17-34 per 100 steps) because of many tiny veins, so the problem is quantity and richness, not mere presence. |
| Not fun to explore | No landmarks (landmark source not wired in M11-0, so this reads 0 by design; M11-3 wires it) and the whole rush route to the deepest cell is 1293 steps, about 5 minutes. The owner's target is about 15 minutes. |
| Connectivity | 14,457 standable cells (about 10%) are not reachable under the walking rule, 13,559 of them in the chaos band. M10 reported 0 under its own, different traversal model; the census is stricter (no long drops). |

## Limits of this baseline

- One live run (one seed), not five. The pure analysis core is covered by unit tests on fixtures; a multi-seed baseline of v1 was not collected because v1 generation is being replaced and each seed costs a full reset plus a roughly 15 minute census. M11-1 onward must meet targets over a fixed seed set.
- `mobs` counts spawner blocks only (the scan stores only cells inside the mine's Y bands, so `open=` counts mine space, not the dimension's surrounding air). Live mobs depend on loaded chunks and are not part of the world's static content.
- `landmarks` is always 0 until the new landmark registry exists (M11-3).
- Rush estimate uses 4.3 blocks/s on 1-step moves; it has not been checked by a timed walk.
